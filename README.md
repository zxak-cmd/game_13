# Игра «Угадай число» (курсовая работа №1)

Консольное приложение на Python 3.6+. Три уровня сложности, рекорды в `records.csv`,
таблица лидеров (топ-10 по каждому уровню), журнал в `game.log`.

Запуск: `python main.py`
Тесты: `python -m unittest -v`

## Структура

- `main.py` — меню и точка входа
- `game.py` — игровая логика (уровни, раунд, сохранение результата)
- `storage.py` — классы `Record` и `Leaderboard` (CSV)
- `utils.py` — ввод с проверкой и настройка логирования
- `config.py` — константы
- `test_storage.py`, `test_utils.py`, `test_game.py` — модульные тесты (42)
