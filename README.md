# Игра «Угадай число» (Курсовая работа №1)

Консольное приложение на Python, в котором игрок должен угадать случайное число в заданном диапазоне. Результаты сохраняются в таблицу лидеров.

## Функционал:
- Три уровня сложности (Лёгкий, Средний, Сложный).
- Ограничение на количество попыток в зависимости от уровня.
- Сохранение рекордов в файл `records.csv`.
- Вывод таблицы лидеров (Топ-10) для каждого уровня.
- Защита от некорректного ввода (буквы вместо цифр, пустые имена, выход за границы диапазона).
- Логирование действий и ошибок в файл `game.log`.

## Структура проекта:
- `main.py` — главное меню и точка входа.
- `game.py` — игровая логика (раунд, уровни).
- `storage.py` — классы `Record` и `Leaderboard` (работа с CSV).
- `utils.py` — проверка ввода и настройка логирования.
- `config.py` — константы и настройки.

## Как запустить:
1. Установите Python (версия 3.6 или выше).
2. Скачайте все файлы проекта в одну папку.
3. Запустите игру в терминале с помощью команды:
   `python main.py`

## Управление:
Игра управляется с помощью ввода цифр в консоли и следования инструкциям на экране (выбор пункта меню, ввод имени, ввод числа).
